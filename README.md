Student Grade Management (Quản lý điểm sinh viên)
Ứng dụng desktop quản lý điểm sinh viên viết bằng C# WinForms, lưu trữ dữ liệu trên SQL Server.
Tính năng

Quản lý thông tin sinh viên: thêm, sửa, xóa, tìm kiếm (CRUD).
Nhập và quản lý điểm theo môn học.
Lưu trữ và truy xuất dữ liệu từ cơ sở dữ liệu SQL Server.
Giao diện trực quan bằng Windows Forms.

Công nghệ sử dụng

Ngôn ngữ: C#
Giao diện: Windows Forms (WinForms)
Cơ sở dữ liệu: Microsoft SQL Server
IDE: Visual Studio

Cách chạy

Mở file qldsv.slnx bằng Visual Studio.
Khôi phục/tạo database SQL Server và cập nhật chuỗi kết nối (connection string) trong project.
Nhấn Start (F5) để build và chạy ứng dụng.

Ghi chú
Trong project có file csdl là query.txt nằm trong service chứa các câu lệnh truy vấn để tạo database
